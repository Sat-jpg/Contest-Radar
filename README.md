# Contest Radar

Chrome extension (Manifest V3) that lists upcoming competitive programming contests from clist.by and reminds you before they start.

## Install (developer mode)
1. Unzip this folder.
2. Open chrome://extensions, enable **Developer mode**, click **Load unpacked**, select the folder.
3. The settings page opens: enter your clist.by username + API key (free: https://clist.by/api/v4/doc/), pick sites, save.

## Files
- manifest.json – extension config, permissions (storage, alarms, notifications, clist.by)
- background.js – service worker: hourly refresh, reminder alarms, notifications
- popup.html/css/js – toolbar popup (Today / This week / All upcoming)
- options.html/js – settings page
- shared.js – site list, clist.by API client, formatting helpers
- icons/ – generated by make_icons.py (python3 + Pillow)
